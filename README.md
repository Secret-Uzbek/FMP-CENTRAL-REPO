[![Navoiy](https://img.shields.io/badge/Alisher%20Navoi-585%20years%20of%20legacy-7B66DC?style=for-the-badge)](https://github.com/Secret-Uzbek/Navoiy-Terra-Corpus)

[![DOI](https://img.shields.io/badge/DOI-Pending-orange?style=flat-square)](https://zenodo.org)
[![Release](https://img.shields.io/github/v/release/Secret-Uzbek/Navoiy-Terra-Corpus?style=flat-square)](https://github.com/Secret-Uzbek/Navoiy-Terra-Corpus/releases)

**Repository:** [Navoiy-Terra-Corpus](https://github.com/Secret-Uzbek/Navoiy-Terra-Corpus)

**First computational corpus** of Alisher Navoi's (1441-1501) literary works with fractal semantic annotations.

**Key Features:**
• 📚 **26 authentic texts** — 13 ghazals, 8 rubaiyat, 5 tuyuqs from "Hazoin ul-maoniy"
• 🔤 **9-language PLT layer** — Chagatai → Uzbek, Russian, English, German, Uyghur, Dari, Pashto, Farsi
• 🕸️ **Interactive semantic network** — D3.js visualization of mystical concepts
• 🤖 **NLP-ready annotations** — JSON-LD format, UTF-8 encoding
• 📖 **Methodology paper** — 2,800 words, peer-ready
• 🌍 **Open Access** — CC BY 4.0, Zenodo DOI pending

**Research Applications:**
• Computational stylometry (ghazal vs. rubai patterns)
• Cross-cultural lexicography (Persian-Turkic continuum)
• Network analysis of Sufi concepts
• Digital humanities pedagogy

**Created for:** V International Symposium "Navoiy and Eastern Renaissance" (Feb 9, 2026, Navoiy, Uzbekistan)

**Status:** ✅ v1.0 Production | 🔄 v1.1 (Layli va Majnun excerpts, Turkish language, web UI)
