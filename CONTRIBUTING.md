# Contributing to FMP-CENTRAL-REPO

`FMP-CENTRAL-REPO` is not a general sandbox.

It is the public hub of the Fractal Metascience Paradigm: a theory-facing,
publication-facing, DOI-facing, and site-facing repository.

That means contributions here must protect public legibility first.

## Repository role

This repository is for:

- public theory bridges;
- publication-facing files;
- citation and DOI surfaces;
- site pages and navigation;
- human-readable entry points into the wider Terra ecosystem.

This repository is not for:

- blind archive dumping;
- machine-routing residue presented as public explanation;
- random regeneration artifacts;
- multilingual chaos at the top surface;
- root-level sprawl without structural necessity.

## Working orientation

All contributions should remain compatible with the Fractal Metascience
Paradigm and its working contour:

- `Main Directive`
- `Sequence Protocol`
- `NULLO`
- `Post-Lingua Trace (PLT)`
- `UCOMM`
- `EUO`
- `Invisible Shadow`
- `TraceLog`
- `Detox`
- `Universal Convention`
- `Terra legal / publication / license donor layer`

This does **not** mean every pull request must restate the whole doctrine.

It means edits must not contradict the doctrine by creating:

- false canon;
- false clarity;
- false provenance;
- false public authority;
- or false completeness.

## Main Directive

Before writing, read.

Before adding, classify.

Before normalizing, identify origin.

Before publishing, check whether the surface is for humans, operators, or
machines.

If a contribution increases noise faster than it increases clarity, it should
not land here.

## Sequence Protocol for edits

Use this order:

1. read the existing file and its role;
2. check whether it is canonical, donor-derived, machine-facing, or shadow
   residue;
3. detox encoding, duplication, and false signals first;
4. only then rewrite or restore content;
5. keep the public surface English-first unless the file is explicitly a
   secondary language surface;
6. verify that README/site/citation/legal surfaces still agree with each other;
7. record the change in `TraceLog` or equivalent continuity notes when the
   change is structurally meaningful.

## Invisible Shadow rule

Assume that a public repository accumulates shadows over time:

- duplicates;
- broken mirrors;
- AI autofix residue;
- half-restored files;
- operational files pretending to be public explanation;
- old multilingual or mojibake fragments.

Do not strengthen the shadow layer by accident.

If you detect a shadow file, either:

- restore it properly,
- mark it honestly,
- relocate it,
- or keep it out of the first-entry human path.

## Detox rule

Detox comes before beautification.

Priority order:

1. remove broken encoding;
2. remove misleading placeholders;
3. remove false human-facing signals from machine/service files;
4. restore provenance where possible;
5. improve readability without inventing false history.

## Language rule

The top public repository surface should remain English-first.

Russian, Uzbek, and other language files may exist where they are meaningful,
but the first human entry to the repository should not require private local
context or knowledge of internal chronology.

## What is welcome here

- README improvement that preserves real repository role
- DOI, citation, and metadata repair
- site-surface repair
- historically grounded restoration
- encoding repair
- human/machine layer separation
- structural navigation improvement
- publication continuity work

## What should not be merged lightly

- generated maps presented as if they were canonical theory
- service-layer files taking over the public root
- mass imports from other repositories without provenance
- archive bundles in the public root
- multilingual duplication without a clear role
- AI-generated copy that was not checked against the real repository function

## Pull request checklist

Before proposing a change, confirm:

- this edit makes the public repository more legible, not less;
- the file role is understood;
- provenance was checked where history matters;
- English-first public entry is preserved;
- no new shadow residue is being introduced;
- legal/citation/publication surfaces remain coherent.
