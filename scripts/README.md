# Скрипты автоматизации FMP-CENTRAL-REPO

Этот каталог содержит скрипты для автоматизации работы с репозиторием.

## 📋 Содержание

1. [check_consistency.py](#check_consistencypy) - Проверка согласованности документации
2. [convert_pdf_to_md.py](#convert_pdf_to_mdpy) - Конвертация PDF в Markdown

---

## 🔍 check_consistency.py

Проверяет согласованность структуры документации между языковыми версиями (EN/RU/UZ).

### Использование

Запустите скрипт из корня репозитория:

    python scripts/check_consistency.py

### Что делает

- Извлекает заголовки (H1, H2) из README.md, README_RU.md, README_UZ.md
- Сравнивает количество разделов между версиями
- Выводит отчёт о расхождениях

### Пример вывода

    ============================================================
    🔍 Проверка согласованности документации FMP
    ============================================================
    
    📄 Базовый файл: README.md
       Найдено заголовков: 12
    
    📄 Сравнение с README_RU.md:
       Найдено заголовков: 4
       ⚠️ Разное количество заголовков!
       Ожидается: 12, Найдено: 4
    
    ============================================================
    ⚠️ Обнаружены расхождения в структуре документации.
       Рекомендуется синхронизировать разделы между языками.
    ============================================================

## 🔄 convert_pdf_to_md.py

Конвертирует PDF файлы в Markdown формат для лучшей индексации и редактирования.

### Требования

    pip install PyMuPDF

### Использование

Запустите скрипт из корня репозитория:

    python scripts/convert_pdf_to_md.py

### Что делает

- Находит все PDF файлы в текущей директории
- Извлекает текст из каждой страницы
- Создаёт Markdown файл с тем же именем
- Сохраняет структуру по страницам

### Пример

Для файла `FMP_Mathematical_Formalization.pdf` будет создан файл `FMP_Mathematical_Formalization.md`.

## 🚀 Автоматизация через GitHub Actions

Все скрипты интегрированы с GitHub Actions (см. `.github/workflows/validate.yml`):

- **При каждом push** автоматически проверяется структура репозитория
- **Валидация JSON файлов** на синтаксические ошибки
- **Поиск утечек токенов** в коде
- **Проверка наличия** ключевых документов

## 📝 Добавление новых скриптов

При добавлении новых скриптов:

1. Создайте файл в директории `scripts/`
2. Добавьте документацию в этот README
3. Убедитесь, что скрипт работает локально
4. При необходимости добавьте проверку в `.github/workflows/validate.yml`
