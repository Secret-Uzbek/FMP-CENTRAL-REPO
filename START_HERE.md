# Start Here

This is the shortest human entry path into the Fractal Metascience Paradigm and the wider Terra ecosystem.

## 1. What this ecosystem is

The Fractal Metascience Paradigm (FMP) is a public research and development ecosystem created to connect fragmented knowledge, ethical AI, multilingual education, cultural memory, and practical implementation layers.

This repository is not the whole archive. It is the public hub: the place where a first-time reader can understand the structure, find the theory, follow the publication trail, and reach the applied branches.

## 2. The simplest reading order

Start in this order:

1. `README.md` — public overview and repository role.
2. `MASTER_MAP.md` — compact map of the wider ecosystem.
3. `META-INDEX.md` — what each root file or folder is for.
4. `ROADMAP.md` — current direction and priorities.
5. `PUBLICATION_RULE.md` — what counts as a public-facing publication surface.
6. `CITATION.cff` — citation metadata.

## 4. For different readers

### If you are a researcher

Read `README.md`, `MASTER_MAP.md`, `CITATION.cff`, and then move to the theory or corpus repository that matches your field.

### If you are an institution

Read `README.md`, `institutional_pitch.md`, `ROADMAP.md`, and the public live surfaces linked from the README.

### If you are a developer

Read `META-INDEX.md`, `PUBLICATION_RULE.md`, `.github/workflows/`, and then move to the relevant implementation repository.

### If you are an AI assistant or automation system

Do not invent content. Work only from the actual repository corpus, files, metadata, workflows, and linked public records. If something is absent, mark any proposed addition as a new proposal, not as existing project reality.

## 5. Current public goal

The immediate goal is public normalization:

- keep the central hub readable;
- separate theory, practice, governance, archive, and machine-facing layers;
- remove broken encoding and placeholder surfaces;
- connect each branch to evidence, citation, and human-readable documentation;
- make the ecosystem understandable to a new reader within a few minutes.

## 6. Short external description

Fractal Metascience is a human-first, open research ecosystem from Uzbekistan that connects theory, ethical AI, multilingual education, cultural memory, and practical prototypes into one citable public architecture.
