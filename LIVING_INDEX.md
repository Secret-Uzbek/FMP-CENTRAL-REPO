# Living Index

This file is the current public index of the living FMP / Terra ecosystem surface.

It is not a full archive. It is not a substitute for the central maps. Its purpose is to show which public layers are active, what role they play, and where a human reader should go next.

## Status

- Public hub: active.
- Theory and publication layer: active.
- Human-facing research branches: active.
- Implementation/MVP branches: active but still under normalization.
- Documentation portal: needs conversion from starter shell into official docs.
- Audit layer: active but should become stricter before public releases.

## Canonical public entry files

1. `START_HERE.md` — shortest human entry path.
2. `README.md` — repository overview and public role.
3. `MASTER_MAP.md` — compact cross-repository map.

5. `ECOSYSTEM_MAP.md` — technical cross-repository map.

## Evidence standard for research branches

Each research branch should gradually include:

- `metadata/sources.csv` or `metadata/sources.json`
- `metadata/claims.csv` or `metadata/claims.json`
- `docs/methodology.md`
- `docs/bibliography.md`
- `Publications/article-draft.md`

Public claims should be traceable to real corpus records.

## Implementation standard for MVP branches

Each implementation branch should gradually include:

- `README.md`
- `CITATION.cff`
- `LICENSE`
- `.env.example` when secrets or tokens are needed
- `DEPLOYMENT.md`
- tests or at least test examples
- clear demo/production distinction
- no placeholder endpoint pretending to be a working service

## Operating rule

Human-first, citation-aware, corpus-grounded.

No fake canon. No invented content. No broken public surface. No machine clutter as the first entry point.
