## Purpose

This file is the central TraceLog registry for stabilizing the GitHub layer of the Fractal Metascience / Terra ecosystem.

It does not replace source archives, DOI records, monographs, publication packages, or repository histories. Its purpose is to classify recurring structural failures, separate safe technical repair from policy-level review, and prevent chaotic file-by-file editing.

## Method stack

- NULLO: freeze assumptions before repair.
- PLT: preserve trace, provenance, context and continuity.
- UCOMM: keep human-readable and machine-readable communication aligned.
- EUO: coordinate distributed repository repair without flattening all layers.
- FMP: treat the GitHub ecosystem as a recursive, multi-layer knowledge system.

## Repository zones

| Zone | Meaning | Allowed action |
|---|---|---|
| Public surface | README, LIVING_INDEX, CITATION, LICENSE, SECURITY, GOVERNANCE, CHANGELOG, Pages entry surfaces | Safe direct repair after file check |
| Publication layer | Articles, monographs, DOI packages, academic drafts | Repair formatting and encoding directly; DOI, evidence and claim issues need audit |
| Raw/archive/session layer | chat dumps, historical HTML mirrors, legacy exports, provenance corpora | Do not rewrite by default; classify and preserve provenance |

## Failure classes

- AUDIT-001: broken Terra audit workflow.
- DONOR-001: donor-layer residue in repository-level files.
- PATH-001: broken reading path or missing file reference.
- MOJI-001: encoding damage in public or publication text.
- META-001: DOI and citation drift.
- LICENSE-001: license conflict.
- CLAIM-001: evidence overclaim.
- RAW-001: raw archive presented as public surface.
- PRIVACY-001: sensitive identity surface.
- BINARY-001: unread binary publication surface.

## Repair workflow

1. NULLO: do not repair before classifying.
2. PLT: preserve repository, path, failure class and commit history.
3. UCOMM: make the repair readable for humans and machines.
4. EUO: apply comparable rules across comparable repositories only where the layer role matches.
5. FMP: update this registry so future agents do not rediscover the same failure from zero.

## Boundaries

- No blind global rewrite.
- No deletion of raw provenance without explicit command.
- No automatic DOI correction.
- No automatic license correction.
- No automatic scientific claim rewriting.
- No treatment of simulation or prototype language as production evidence.
