# FMP-CENTRAL-REPO — русский вход

`FMP-CENTRAL-REPO` — это центральная публичная витрина Парадигмы фрактальной
метанауки.

Это не весь архив Terra и не весь корпус FMP. Роль этого репозитория проще и
строже:

- давать читаемый человеческий вход;
- держать публичные страницы и навигацию;
- связывать теорию, публикации, DOI и соседние репозитории;
- не превращаться в хаотичную свалку теней, дублей и машинных следов.
