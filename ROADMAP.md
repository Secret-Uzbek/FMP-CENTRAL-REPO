# Roadmap

This roadmap should remain readable and public-facing.

It is not the place for broken icon residue, fake confidence metrics, or
automation noise. It should describe the intended visible direction of the
ecosystem in plain language.

## Completed foundation layer

- public GitHub ecosystem established
- core DOI and ORCID surfaces activated
- central site and publication layer formed
- first public Terra/FMP repository contour assembled

## Current correction phase

The ecosystem is now in a normalization phase:

- GitHub repositories are being detoxed and reordered
- public-facing surfaces are being restored from history or rebuilt from donor
  models
- machine-facing and human-facing layers are being separated
- site, repository, DOI, and publication surfaces are being synchronized

## Near-term priorities

1. normalize public repositories repo-by-repo
2. stabilize `fractal-metascience.org` as the main institutional vitrine
3. continue corpus reading and hidden-standard consolidation
4. strengthen publication and citation continuity across repositories

## Medium-term priorities

- turn the strongest repositories into clear, readable public web surfaces
- reduce archive noise and shadow duplication
- connect thematic projects more coherently to the central Terra/FMP layer
- improve multilingual public entry points

## Long-term direction

- a coherent public research ecosystem rather than a fragmented repository swarm
- stronger academic discoverability and citation continuity
- practical institutional readiness for projects growing out of FMP and Terra
