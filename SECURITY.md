# Security Policy

This file is the repository-specific security note for `FMP-CENTRAL-REPO`.

This repository is a public hub and live site surface. Its security scope is
therefore narrower than the whole Terra ecosystem, but broader than a plain
static website.

## What belongs here

Report issues that affect:

- repository integrity;
- public Pages/site surfaces;
- publication metadata and DOI-facing materials;
- site scripts, worker configuration, and deployment-related files;
- accidental exposure of sensitive data in the public repository.

## What does not belong here

This repository is not the right place to treat every Terra-wide operational or
infrastructure problem as if it were a central-repo bug.

Broader legal/governance/security donor logic belongs to:

- `AIUZ-Terra-Codex-EcoSystem/terra-legal`

## Reporting

Please report security concerns to:

- `a.abdukarimov@fractal-metascience.org`

When reporting, include:

- what file or surface is affected;
- how the problem can be reproduced;
- whether public readers, repository integrity, or deployment are affected.

## Disclosure rule

Do not publish exploit details publicly before the issue is reviewed and a fix
path exists.
